1. Stationarity Analysis (Augmented Dickey-Fuller Test)¶

Before running any regression, we must ensure that our time-series variables are stationary to avoid spurious results.

In [3]:
def adf_test(series, title=''):
    print(f'=====================================================')
    print(f'Augmented Dickey-Fuller Test: {title}')
    print(f'=====================================================')
    result = adfuller(series.dropna(), autolag='AIC')
    labels = ['ADF Test Statistic', 'p-value', '#Lags Used', 'Number of Observations Used']
    out = pd.Series(result[0:4], index=labels)
    for key, value in result[4].items():
        out[f'Critical Value ({key})'] = value
    print(out)
    
    if result[1] <= 0.05:
        print("=> Result: STATIONARY\n")
    else:
        print("=> Result: NON-STATIONARY\n")

adf_test(df['GDP_Growth_Pct'], 'Real GDP Growth')
adf_test(df['Brent_Oil_Price_USD_Barrel'], 'Brent Oil Price')
adf_test(df['CPI_Index'], 'Inflation (CPI Index)')

Testing the significance of global shocks (USD Index, Fed Rate) compared to local/commodity shocks (Oil Price) on regional growth.

# تجهيز البيانات
df_panel = df.set_index(['Country', 'Year'])
df_panel = df_panel.dropna(subset=['GDP_Growth_Pct', 'Brent_Oil_Price_USD_Barrel', 'US_Dollar_Index', 'Fed_Rate_Pct'])

# المتغير التابع والمستقلات
Y = df_panel['GDP_Growth_Pct']
X = sm.add_constant(df_panel[['Brent_Oil_Price_USD_Barrel', 'US_Dollar_Index', 'Fed_Rate_Pct']])

# النموذج
mod = PanelOLS(Y, X, entity_effects=True)
res = mod.fit(cov_type='clustered', cluster_entity=True)

print("=====================================================")
