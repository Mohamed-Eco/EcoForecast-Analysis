# 🌍 EcoForecast: North Africa Macro-Financial Monitor (2015-2025)

> **"Beyond the Fed Rate: How Does the Strong Dollar Reshape Macro-Financial Resilience in North Africa?"**

## 📌 Executive Summary
EcoForecast is an end-to-end macroeconomic analytical ecosystem designed to assess the impact of US monetary policy (Fed Rate & USD Index) on the economic growth of five North African countries: Algeria, Egypt, Libya, Morocco, and Tunisia. 

Rather than relying on theoretical assumptions, this project utilizes **Econometric Modeling (PanelOLS)**, **Time-Series Stationarity Tests (ADF)**, and **Interactive Data Visualization** to prove that the **US Dollar Index (DXY)** —not the Fed Rate directly—is the primary transmission channel of global shocks to the region (P-value = 0.0156).

## 🛠️ Tech Stack & Methodology
This project is a full-stack data pipeline:
*   **Data Preprocessing & Visualization:** Python (Pandas, Seaborn, Matplotlib, Statsmodels).
*   **Econometric Analysis:** Stata (PanelOLS with Fixed Effects) & Python (Linearmodels).
*   **Business Intelligence & Storytelling:** Power BI (DAX, Custom Visuals, AI Decomposition Trees).
*   **Web Deployment:** GitHub Pages (HTML Export from Jupyter Notebook).
